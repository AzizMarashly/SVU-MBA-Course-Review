Non-exam sources:
| code | what | how to use |
|---|---|---|
| BOOK | The textbook's end-of-chapter review sets (T/F, MCQ, definitions, essays). The book marks its answers inline (a tick in the صح/خطأ column, the correct MCQ option highlighted in yellow; `marked_by` key/highlight in book.json). The mark is the BOOK's answer: verify it against the chapter text; if the text contradicts it, answer from the text and put the mark on `book_says`. Essays carry no answer. | type "textbook" |
| ASM | Asem summary of the current book, reproduces the review sets with worked answers. | Independent cross-check (§8): add "ASM" to `sources` of the book question it confirms; if it disagrees with the book, book wins and its answer goes to `other_source="ASM: …"`. Report agreement count. |
| OQ1 | Older-curriculum exam compilation (اسئلة_دورات_مجمعة + its copy تجميعة_2). | type "other": include ONLY items whose concept exists in the current book; verify the answer from the book, never from the file's key; skip the rest (count in report). |
| OQ2 | Older-curriculum question file أسئلة_من_مقرر + its key حل أسئلة MIS.docx. | same rule |
| OQ3 | Older-curriculum Q&A compilation MIS Q.pdf. | same rule |
| OQ4 | Older-curriculum answer key photographed (دورات.pdf + MISS photos). | same rule |
| OQ5 | Older-curriculum lecturer notes (ملاحظات_مقرر) + 2019-01-24 exam recollection. | same rule |
| GEN | Generated by this review (§9). | type "generated" only |

`exam_sources` ⊆ {S25, R44, F24}. A question found twice inside the same sitting counts once. Types are derived from
sources by `build_bank.py`: exam ⇔ an exam sitting has it; textbook ⇔ BOOK; other ⇔ any OQ code; ASM is never a type.
