تُضاف المراجعات تباعاً خلال الفصل

💡 كل مراجعة ملف HTML واحد. حمّله وافتحه من هاتفك أو حاسوبك بلا إنترنت، أو أرسله لزملائك كما هو. ملاحظاتك وفلاترك تُحفَظ في المتصفح.

⚠️ اقرأ قبل الاعتماد على أي مراجعة: هذه الملفات مُولَّدة بالذكاء الاصطناعي من مواد المادة، وقد رُوجعت جزئياً فقط. قد تحتوي إجابات خاطئة، أو أسئلة أُسيء فهمها، أو أرقام صفحات غير دقيقة. استخدمها كأداة تنظيم ومراجعة إلى جانب الكتاب، لا كبديل عنه. إن وجدت خطأً، أبلغ عنه عبر صفحة المشاكل على GitHub ليُصحَّح في الإصدار التالي.

ماذا تجد داخل كل مراجعة؟

كل ملف HTML مستقل بالكامل، يمكن حفظه وفتحه على الهاتف أو الحاسوب بلا اتصال.

✅

إجابات مرجَّعة إلى الكتاب

كل إجابة تشير إلى صفحة في الكتاب لتتحقق منها بنفسك. الأسئلة منخفضة الثقة مُعلَّمة، لكن قد توجد أخطاء غير مُعلَّمة أيضاً.

🎯

درجة أهمية تقديرية

تقدير لكل سؤال حسب تكراره في الدورات السابقة، وليس تنبؤاً بما سيأتي في الامتحان.

🔍

فلاتر ذكية

صفّي حسب الفصل أو المصدر أو الأهمية، وطيّ الفصول لمراجعة سريعة.

📝

مصادر متعددة

أسئلة الكتاب، الدورات السابقة، والملخصات المتداولة، مدمجة قدر الإمكان بلا تكرار.

مولّد المراجعات

هذه الصفحات لا تُكتب يدوياً. تُبنى بواسطة برومبت مفتوح المصدر يعمل مع Claude Code على مجلد المادة.

  1. اجمع الكتاب والدورات السابقة والملخصات في مجلد واحد.
  2. املأ جدول PROJECT SETTINGS في أعلى البرومبت (اسم المادة، الفصول، لغة الأسئلة…).
  3. الصق البرومبت كاملاً في Claude Code داخل ذلك المجلد، واترك الباقي له.
اقرأ البرومبت (v0.8) سجل التغييرات الرخصة
🤝 عهد المجتمع: شارك المراجعات مجاناً مع زملائك، أبقِ إشارة المصدر داخل الملف، ولا تبعها أو تضعها خلف اشتراك. الكتب والدورات ملك لأصحابها.

ساهم في تحسين المراجعات

هذا مشروع طلابي مفتوح. كل تصحيح يفيد من يأتي بعدك، ولا يحتاج أي تصحيح إلى خبرة برمجية.

🐞

وجدت خطأً؟ أبلغ عنه

افتح بلاغاً على GitHub واذكر المادة والفصل ونص السؤال، ورقم الصفحة في الكتاب إن أمكن. هذا يكفي.

📄

عندك دورة أو ملخص جديد؟

أضفه إلى مجلد المادة في المستودع وشغّل البرومبت، أو أرسله في بلاغ وسيُدمج في الإصدار التالي. احذف أي بيانات شخصية أولاً.
